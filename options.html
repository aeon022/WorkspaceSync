The Custom UI Modification script that supplies real Vivaldi workspace names is at uimod/workspacesync-uimod.js inside this extension's folder on disk. To register it, go to Vivaldi Settings → Appearance → Custom UI Modifications and point the JavaScript field at that file's full path. This step is entirely optional — WorkspaceSync works fully without it, just with typed-in labels instead of suggested names.

WorkspaceSync is free. If it's useful, you can buy the developer a coffee on Polar.sh.
