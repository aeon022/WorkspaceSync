Vivaldi only exposes which workspace a tab belongs to from its own privileged UI context — never to a regular extension. Without this step, every tab shows up as a single undifferentiated workspace. The script is at uimod/workspacesync-uimod.js inside this extension's folder on disk. To register it, go to Vivaldi Settings → Appearance → Custom UI Modifications and point the JavaScript field at that file's full path, then restart Vivaldi. It also supplies your real Vivaldi workspace names as label suggestions.

WorkspaceSync is free. If it's useful, you can buy the developer a coffee on Polar.sh.
